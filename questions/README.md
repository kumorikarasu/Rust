# AoC

Daily prompts (AoC 2023):
- Day 1: Pull the first/last digit (numeric or spelled) from each line to form calibration values and sum them.
- Day 2: Validate cube games against color limits; then compute the minimum cube set (power) for each game and sum.
- Day 3: On a grid, any number touching a symbol counts as a part number; gear symbols multiply adjacent numbers for ratios.
- Day 4: Scratchcards score with doubling points per match and chain-react to create copies of subsequent cards.
